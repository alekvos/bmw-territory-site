# BMW Территория — размещение и передача проекта

Актуально на 20 августа 2026 года.

## Где находятся файлы

Проект существует в трёх экземплярах:

1. Рабочая копия разработчика — `C:\Users\Пользователь\Documents\bmw territory site`.
2. Исходники и история версий — GitHub-репозиторий `alekvos/bmw-territory-site`.
3. Опубликованная сборка — сервер Timeweb Cloud. Релизы находятся в `/var/www/bmw-territory/releases/`, а `/var/www/bmw-territory/current` указывает на активный релиз.

Сервер хранит готовую сборку для посетителей, а GitHub — исходники и историю изменений. Файлы на сервере не следует редактировать вручную: изменения вносятся в рабочую копию, проверяются и публикуются новым релизом.

## Текущая схема связи

Сайт не содержит формы обратной связи и не создаёт базу заявок. Все основные кнопки ведут в блок прямой связи, где посетитель самостоятельно выбирает:

- телефонный звонок;
- MAX;
- WhatsApp;
- Telegram.

Сайт не получает содержание звонка или сообщения и не пересылает контактные данные на почту, в CRM либо на отдельный серверный обработчик. Почтовый пароль, SMTP и API заявок проекту не требуются.

## Порядок обновления сайта

1. Внести изменения в рабочую копию.
2. Выполнить `npm run build` и проверить каталог `dist/`.
3. Зафиксировать изменения в Git и отправить их в ветку `main`.
4. Создать на сервере новый каталог релиза и загрузить в него содержимое `dist/`.
5. Проверить конфигурацию командой `nginx -t`, переключить ссылку `current` на новый релиз и перезагрузить Nginx.
6. Проверить главную, страницы услуг, политику, страницу 404, HTTPS и мобильную версию. Предыдущий релиз оставить для быстрого отката.

Политика конфиденциальности остаётся на сайте и описывает:

- технические данные, которые могут обрабатываться сервером и хостингом для показа страниц и безопасности;
- отсутствие сбора имён, телефонов и сведений об автомобиле непосредственно через сайт;
- добровольный переход пользователя в телефон или внешний мессенджер;
- загрузку карты Яндекса только по запросу пользователя.
