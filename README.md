# BMW Территория — прототип

Премиальный одностраничный прототип профильного автосервиса BMW с вторичным направлением Mercedes-Benz.

## Запуск

Проект не требует сборки. Откройте `index.html` в браузере или запустите локальный сервер:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Что внутри

- адаптивная вёрстка для desktop, tablet и mobile;
- SVG-автомобиль и схемы услуг без внешних изображений;
- анимация появления автомобиля, вращение колёс и параллакс;
- переход между разделами длительностью менее секунды;
- анимации появления, счётчиков, схем и формы записи;
- шрифты Unbounded, Playfair Display Italic, Golos Text и JetBrains Mono.

Контакты и адрес в прототипе являются заглушками и должны быть заменены реальными данными заказчика.
