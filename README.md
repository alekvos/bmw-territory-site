# BMW Территория — сайт автосервиса

Премиальный одностраничный сайт профильного сервиса BMW с дополнительным направлением Mercedes-Benz.

## Адреса

- Основной домен: https://bmw-territory.ru
- GitHub Pages: https://alekvos.github.io/bmw-territory-site/
- Репозиторий: https://github.com/alekvos/bmw-territory-site

GitHub хранит исходники и историю изменений. Рабочая версия сайта размещена отдельным релизом на сервере Timeweb Cloud; обновление выполняется после проверки сборки. Подробная схема размещения, передачи и обновления описана в [HANDOVER.md](./HANDOVER.md).

Форма записи подготовлена к отправке через отдельный серверный сервис и Яндекс SMTP. До добавления пароля приложения посетителю предлагается резервный переход в WhatsApp. Схема установки и перечень переменных описаны в [ops/README.md](./ops/README.md); реальные почтовые пароли в репозитории не хранятся.

## Локальный запуск

Установите Node.js и запустите локальный сервер:

```powershell
npm run dev
```

Для локальной проверки API в отдельном терминале:

```bash
npm run dev:api
```

Затем откройте http://localhost:4173.

Для подготовки статического каталога `dist/` также доступна команда:

```powershell
npm run build
```

## Что внутри

- адаптивная вёрстка для desktop, tablet и mobile;
- премиальная BMW-палитра и типографика Unbounded, Playfair Display Italic, Golos Text и JetBrains Mono;
- анимированный hero, параллакс, reveal-эффекты, магнитные кнопки и короткие переходы между разделами;
- фотоматериалы услуг, форма записи и загружаемая по запросу интерактивная карта;
- реальные контакты и точка сервиса на Яндекс Картах.
